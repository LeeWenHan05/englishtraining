Set B 1 · Sarahshow
Remember: uncomfortable → listen → protect → report
The main problem is that Sarah feels uncomfortable and may not feel safe. First, I would talk to her privately and understand what happened. I would make sure she does not have to work alone with David for now. Then I would report the issue properly so it can be checked fairly.
Follow-up: What if David denies it?
I would check the facts, such as messages, schedules or witnesses if there are any. I would also hear David's side, but Sarah's safety would still come first.
Set B 2 · Ahmadshow
Remember: fraud → records → report → protect
The main issue is serious misconduct. Ahmad should not ignore it or become part of it. First, he should keep clear records of what he has actually seen. Then he should report it through a proper internal channel. If nothing happens, he may need to take it to a higher level.
Follow-up: What if Ahmad is afraid of losing his job?
I understand why he would be worried. I would tell him to keep the report factual, use a proper channel and protect his own records. But I would still not advise him to take part in something dishonest.
Set B 3 · Mei Lingshow
Remember: health → understand → support → review
The main issue is Mei Ling's health and the effect on the team. First, I would talk to her privately and understand her condition. Then I would check with HR for a safe temporary arrangement. After that, I would review the situation again and see whether the arrangement is working.
Follow-up: What if the team says this is special treatment?
I would explain that the arrangement is temporary because of a health issue. Fairness does not always mean treating every situation in exactly the same way.
Set B 4 · Krishnanshow
Remember: racism → record → report → escalate
The main issue is racist abuse and the poor response from the Team Leader. First, Krishnan should write down what happened and make a formal report. He should also ask the company how it protects staff from abusive customers. If the issue is ignored, he should take it to a higher level.
Follow-up: What if the customer is important?
The company can still stay professional with the customer, but I would not ask an employee to accept racist abuse. There still needs to be a clear boundary.
Set B 5 · Marcusshow
Remember: favouritism → facts → clear criteria → escalate
The main issue is possible favouritism. First, I would check how projects are being given out and compare the performance of the team members. Then I would ask for clearer criteria for future projects. If the same unfair pattern continues, I would raise the issue to a higher level.

Then he may deserve some difficult projects. But the criteria should still be clear, and the other team members should also get chances to develop.

Set B 7 · Aishashow
Remember: records → process → no proof → fair review
The main issue is that there is no clear proof that Aisha lost the book. First, I would check the system records and the normal return process. Then I would explain the evidence calmly and ask the manager to follow the normal dispute process. I would not ask Aisha to pay just to end the complaint.

I would say the easiest solution is not always the fairest one. If an employee is forced to pay without proof, it can create a bad example for future cases.
